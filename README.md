# 여우랑 일본어 (JLPT N5~N1 단어·문법·한자 학습 자료)

개인 학습용 앱 "여우랑 일본어"가 불러 쓰는 자료 저장소입니다.
JLPT N5~N1 단어 8,034개와 여행 단어 50개의 그림(GIF)·발음·예문, 문법 828항목과 기초 문법 강의 30개, 한자 1,974자의 풀이가 들어 있습니다.

- `index.html` : 학습 앱 본체 (웹 브라우저에서도 열립니다)
- `data/` : 단어·예문·문법·한자 풀이 데이터
- `pack/` : 그림(GIF)과 음성(mp3)을 묶은 파일
- `manifest.txt` : 파일 목록과 버전 (앱이 바뀐 파일만 다시 받는 데 사용)
